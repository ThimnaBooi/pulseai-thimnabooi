# PulseAI

**PulseAI** is an AI-powered sentiment intelligence platform that collects and analyzes **real Western Cape news** using Natural Language Processing (NLP). It classifies articles as **Positive**, **Neutral**, or **Negative** and presents the results through an interactive dashboard with meaningful insights and visualizations.

## Features

* 📰 Fetches real Western Cape news from trusted news APIs
* 🤖 AI-powered sentiment analysis with confidence scores
* 📊 Interactive dashboard with charts and statistics
* 📈 Sentiment trends over time
* 🏙 Municipality and category analysis
* 🔍 Search and filter functionality
* 💡 AI-generated insights
* 📄 PDF report generation
* 📂 CSV import and export
* 🌙 Responsive design with Light and Dark Mode

## Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/pulse-ai.git
cd pulse-ai
```

Install dependencies:

```bash
npm install
pip install -r requirements.txt
```

Create a `.env` file and add your news API keys.

Run the application:

```bash
npm run dev
uvicorn main:app --reload
```
